# Find Lens Examples

## Example 1

### Input

```md
Observation

Startup A solved a problem. Failed.

Startup B solved a problem. Failed.

Startup C solved a problem. Failed.

Common Thread

Solving problems is not enough.

Candidate Lens

Startup founders face a crisis of faith.
```

### Output

```md
# Evaluation

## Subject

Thought piece about startup success.

## Existing Structure

### Everyone thinks

Startups succeed by solving problems.

### But

Many startups solve real problems and still fail.

### Because

Solving a problem does not automatically create word-of-mouth.

### Which means

Startup founders face a crisis of faith.

## Lens

Current Lens:

Startup founders face a crisis of faith.

Alternative Lenses:

1. Utility gets adoption. Remarkability gets distribution.
2. People don't share solutions. They share stories.
3. Startups compete for conversations, not customers.
4. Products spread through stories, not utility.
5. The most important feature is story-worthiness.

## Criteria

| Criteria            | Score | Notes                            |
| ------------------- | ----- | -------------------------------- |
| Observation Quality | 8/10  | Concrete examples.               |
| Tension Quality     | 8/10  | Useful products often fail.      |
| Explanatory Power   | 4/10  | Crisis of faith explains little. |
| Reframe Strength    | 5/10  | Unexpected but weakly connected. |
| Memorability        | 7/10  | Easy to remember.                |
| Portability         | 3/10  | Difficult to apply elsewhere.    |

## Findings

### Pattern

Useful products frequently fail despite solving genuine problems.

### Tension

People expect:

Useful products should succeed.

Yet:

Many useful products fail.

### Why The Lens Works

Creates a surprising angle.

### Why The Lens Fails

Does not explain the observations.

Feels disconnected from startup growth dynamics.

## Recommendation

Recommended Lens:

People don't share solutions. They share stories.

Reason:

Directly explains why useful products fail while remarkable products spread.

## Stronger Reframe

Everyone thinks:

Startups win by solving problems.

But:

Many products that solve problems still fail.

Because:

Utility gives people a reason to use something, not a reason to talk about it.

Which means:

People don't share solutions. They share stories.
```

## Example 2

### Input

```md
Observation

Building plans are frequently lost.

Surveyors redraw plans.

Homeowners cannot find documentation.

Maintenance records disappear after ownership changes.

Candidate Lens

Buildings have a memory problem.
```

### Output

```md
# Evaluation

## Subject

Thought piece about information loss across a building lifecycle.

## Existing Structure

### Everyone thinks

Buildings have a documentation problem.

### But

Documentation already exists in many cases.

### Because

Information is repeatedly lost during handovers.

### Which means

Buildings have a memory problem.

## Lens

Current Lens:

Buildings have a memory problem.

Alternative Lenses:

1. Buildings suffer from organisational amnesia.
2. Building data dies at handover.
3. Buildings forget their own history.
4. Construction has a continuity problem.
5. Buildings are knowledge assets, not physical assets.

## Criteria

| Criteria            | Score | Notes                                         |
| ------------------- | ----- | --------------------------------------------- |
| Observation Quality | 9/10  | Strong evidence across multiple stakeholders. |
| Tension Quality     | 9/10  | Information exists yet keeps disappearing.    |
| Explanatory Power   | 10/10 | Explains many observed behaviours.            |
| Reframe Strength    | 10/10 | Shifts from documentation to memory.          |
| Memorability        | 10/10 | Short and repeatable.                         |
| Portability         | 9/10  | Applies to many lifecycle problems.           |

## Findings

### Pattern

Knowledge is repeatedly lost when responsibility changes.

### Tension

People expect:

Creating documentation should preserve knowledge.

Yet:

Knowledge keeps disappearing.

### Why The Lens Works

Explains:

- Lost plans
- Lost specifications
- Lost manuals
- Lost maintenance history
- Redrawing work

Using a single mental model.

### Why The Lens Fails

Does not directly explain why memory is lost.

Requires supporting evidence in the article.

## Recommendation

Recommended Lens:

Buildings have a memory problem.

Reason:

Strong explanatory power and memorable category shift.

## Stronger Reframe

Everyone thinks:

Buildings have a documentation problem.

But:

Many buildings already have documentation.

Because:

Knowledge is repeatedly lost at ownership and responsibility handovers.

Which means:

Buildings have a memory problem.
```
